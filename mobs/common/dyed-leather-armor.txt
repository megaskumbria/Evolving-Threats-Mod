DYED LEATHER ARMOR ON MOBS
==============================

Type: shared mechanic for zombies, skeletons, and strays.
Code: RandomArmor.java (“SETTINGS” block and dyeLeather method).


HOW IT WORKS
------------
1. Mob gets armor (as before). If any piece is leather, one roll per mob for dyeing
   (LEATHER_DYE_CHANCE, default 50%).
2. If it succeeds — one color for the whole set. Each leather piece has 25% chance
   (LEATHER_PIECE_OWN_COLOR_CHANCE) to get its own color.
3. Color — any of 16,777,216 shades (random red, green, blue).
   Only leather is dyed; iron, diamond, etc. are not dyed in-game.
4. Color is kept on dropped armor.
5. Armor enchants (MobEnchantments) do not change color; both can be on one piece.


IF COLORS LOOK “MUDDY”
----------------------
Among 16.7M random colors many are dull gray-brown.
Set LEATHER_USE_ONLY_DYE_COLORS = true — then only 16 clean dye colors.


SETTINGS (RandomArmor.java)
----------------------------
  LEATHER_DYE_CHANCE ............... 0.50 — chance mob wears dyed leather (per mob, not per piece)
  LEATHER_PIECE_OWN_COLOR_CHANCE ... 0.25 — chance one piece gets its own color
  LEATHER_USE_ONLY_DYE_COLORS ...... false — true = only 16 dye colors
