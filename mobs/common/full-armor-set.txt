FULL ARMOR SET
=====================

Type: normal zombie, skeleton, and stray.
Code: RandomArmor.java (FULL_SET_CHANCE and tryFullSet),
     threat/ThreatTable.java (FULL_ARMOR_SET_CHANCE_START).


HOW IT WORKS
------------
1. GROWING. On day one there is no chance: full diamond on day one does not appear.
   By day 100 chance is FULL_SET_CHANCE (2%). Moon shifts it slightly like other armor.
2. If it rolls — all four pieces same material.
   Leather, gold, chain, copper, iron, and diamond equally likely.
   By endgame full diamond set — roughly one mob in 300.
3. If not — armor as before: each slot separate, mixed materials.
4. Leather set may be dyed like any leather armor.
5. Such a mob’s helmet is not replaced by pumpkin, spawner, or dispenser.
   Named mobs (Excalibur, Mjölnir, sorcerer, overseer, captain, “700 IQ”) skip this roll.
6. Each piece drops at the same chance as normal armor (~8.5%). Whole set does not drop as one item.


SETTINGS
---------
  RandomArmor.FULL_SET_CHANCE ................ 0.02 — 2% on day 100. 0 = off.
  ThreatTable.FULL_ARMOR_SET_CHANCE_START .... 0 — chance on day one. 0.01 = 1% from start.
