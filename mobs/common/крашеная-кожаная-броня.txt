КРАШЕНАЯ КОЖАНАЯ БРОНЯ У МОБОВ
==============================

Тип: общая механика для зомби, скелетов и странников.
Код: RandomArmor.java (блок «НАСТРОЙКИ» и метод dyeLeather).


КАК РАБОТАЕТ
------------
1. Моб получает броню (как раньше). Если среди кусков есть кожаные, один раз на моба бросается шанс покраски
   (LEATHER_DYE_CHANCE, по умолчанию 50%).
2. Если выпало — выбирается один цвет на весь комплект. Каждый кожаный кусок с шансом 25%
   (LEATHER_PIECE_OWN_COLOR_CHANCE) получает свой собственный цвет.
3. Цвет — любой из 16 777 216 оттенков (случайные красный, зелёный, синий).
   Красится только кожа; железо, алмаз и т.д. в игре не красятся.
4. Цвет сохраняется на выпавшей броне.
5. Чары на броне (MobEnchantments) цвет не меняют, оба эффекта могут быть на одном куске.


ЕСЛИ ВЫШЛО «ГРЯЗНО»
-------------------
Среди 16,7 млн случайных цветов много тусклых серо-коричневых.
Поставь LEATHER_USE_ONLY_DYE_COLORS = true — тогда будут только 16 чистых цветов красителей.


НАСТРОЙКИ (RandomArmor.java)
----------------------------
  LEATHER_DYE_CHANCE ............... 0.50 — шанс, что моб в крашеной коже (на моба, не на кусок)
  LEATHER_PIECE_OWN_COLOR_CHANCE ... 0.25 — шанс отдельного куска получить свой цвет
  LEATHER_USE_ONLY_DYE_COLORS ...... false — true = только 16 цветов красителей
